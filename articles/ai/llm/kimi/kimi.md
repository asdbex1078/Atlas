### 💡 Kimi 的技术特色

**MuonClip 优化器（K2 引入）**：Kimi 是第一个大规模使用 Muon 优化器的团队。Muon 比 AdamW 更省 token，但会导致注意力 logits 爆炸。Kimi 为此发明了 **QK-Clip**——在权重更新后直接缩放 Query 和 Key 的投影矩阵，把注意力 logits 控制在阈值内，且不改变当前 step 的前向/反向计算。

**KDA 混合线性注意力（Linear 引入，K3 继承）**：传统线性注意力在长序列上会“遗忘”。KDA 给每个特征维度独立的遗忘门（channel-wise gating），配合 3:1 的线性/全注意力交替结构，在 1M 上下文下 KV cache 减少 75%，解码吞吐提升 6 倍。

**Agentic 数据合成（K2 引入）**：Kimi 构建了一套**多轮工具调用轨迹合成流水线**，从 GitHub 抓取 3000+ 真实 MCP 工具，再通过分层领域演化合成 20000+ 合成工具，用 LLM 生成模拟用户和任务，在模拟环境中产生数万条高质量 agentic 训练数据。
