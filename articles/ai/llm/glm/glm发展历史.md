GLM（General Language Model）系列由清华大学知识工程实验室与智谱AI（Z.ai）联合研发，走的是 **“学术底蕴 + 开源生态 + Agentic 工程”** 路线。与 Qwen 的全尺寸覆盖、DeepSeek 的极致效率不同，GLM 的核心标签是 **“ARC 三位一体”（Agentic + Reasoning + Coding 原生融合）** 和 **国产算力全栈适配**。

### 💡 GLM 的技术特色

**“瘦高”MoE 架构（GLM-4.5 引入）**：与 DeepSeek/Kimi 追求“宽”（更多专家、更大隐藏维度）不同，GLM 选择减少宽度、**增加深度**，在 5120 隐藏维度下使用 **96 个注意力头**（常规模型的 2.5 倍）。GLM 团队发现：更深的模型在推理能力上表现更出色 。

**Muon 优化器 + QK-Norm**：GLM-4.5 采用了 Muon 优化器加速收敛，并引入 QK-Norm 稳定训练，为 ARC 能力打下推理基础 。

**ARC 三位一体设计哲学**：GLM-4.5 的核心主张是 **Agentic + Reasoning + Coding 原生统一**。智谱认为，衡量 AGI 的第一性原理是在不损失原有能力的前提下融合更多通用智能能力，而这三者存在紧密的内在逻辑——Agent 需要代码与推理来“思考和行动” 。

**国产算力全栈适配**：GLM-5 训练全程基于**华为昇腾芯片**完成，并适配摩尔线程、海光、寒武纪、昆仑芯、天数智芯、燧原等国产算力平台，目标是在国产 GPU 生态上实现自主可控 。
