# Qwen（通义千问）开源模型迭代史：从Qwen到Qwen3.8的技术演进

## 前言

Qwen（通义千问）是阿里巴巴通义实验室自2023年起持续开源的大语言模型系列，已成为全球衍生模型数量最多、下载量最大的开源大模型家族。与DeepSeek聚焦极致MoE稀疏化和推理效率不同，Qwen走的是 **“全尺寸、跨模态、广开源”** 的路线，从0.5B的端侧模型到近4000B参数的旗舰MoE，构建了覆盖文本、视觉、音频、代码、智能体的完整生态。


## 2023年：Qwen系列开源起步

**发布时间**：2023年4月（通义千问大语言模型系列发布），2023年8月（首发开源Qwen系列模型）

**核心技术**：初代Qwen奠定了系列的基础架构，采用标准Transformer解码器结构

**解决的问题**：阿里正式进入大语言模型开源赛道，为后续快速迭代建立技术底座和开发者生态


## 2024年：Qwen1.5与Qwen2系列

**Qwen1.5（2024年初）**：在训练数据规模、模型参数效率上进行优化，提升多轮对话和长文本处理能力，为后续版本打下基础

**Qwen2系列（2024年中）**：
- **多语言能力**：支持超过27种语言
- **长上下文**：支持128K tokens上下文窗口
- **架构优化**：引入Grouped Query Attention（GQA）降低KV Cache内存占用，采用SwiGLU激活函数和RoPE位置编码

**解决的问题**：使Qwen在中文理解和多语言场景中具备竞争力，同时GQA的引入为后续长上下文和高效推理铺平道路


## 2024年12月：Qwen2.5——数据规模的跃升

**发布时间**：2024年12月19日

**参数量**：0.5B / 1.5B / 3B / 7B / 14B / 32B / 72B（稠密），以及Qwen2.5-Turbo和Qwen2.5-Plus（MoE变体）

**核心技术**：
- **预训练数据从7T tokens扩展至18T tokens**，重点强化知识、代码和数学领域
- **后训练数据超100万样本**，采用SFT + DPO（离线）+ GRPO（在线）多阶段强化学习
- **MoE架构**：在稠密模型基础上，用MoE层替换标准FFN层，实现细粒度专家分割和共享专家路由
- **统一Token词表**：151,643个常规token，控制token从3个扩展至22个，新增工具调用专用token

**解决的问题**：Qwen2.5-72B-Instruct在多项基准上超越Llama-3-405B-Instruct（参数规模约为其5倍），证明了“数据质量与训练策略”可以部分弥补参数规模的差距。同时将生成长度从2K扩展至8K，显著改善了结构化输入输出（表格、JSON）和工具使用能力

**论文**：Qwen2.5 Technical Report, arXiv:2412.15115


## 2025年4月：Qwen3——混合推理与MoE的融合

**发布时间**：2025年4月

**参数量**：全尺寸稠密与MoE混合，包括0.6B、1.7B、4B、8B、14B、32B，以及30B-A3B和235B-A22B（MoE）

**核心技术**：
- **混合推理（Hybrid Reasoning）**：国内首款将“快思考”（非推理模式）与“慢思考”（推理模式）集成到同一模型中的方案，可针对不同复杂度任务自适应调配算力
- **MoE架构**：235B总参数，22B激活参数，预训练数据达36T tokens
- **Agent能力原生增强**：原生支持MCP协议与复杂工具调用，在BFCL智能体评估中以70.8分领先Gemini 2.5-Pro和OpenAI-o1
- **100+语言支持**：具有强大的多语言理解、推理和生成能力

**解决的问题**：解决了“推理模型不能做Agent”的痛点，让同一个模型既能深度推理，又能调用工具完成复杂任务。在AIME25数学推理和LiveCodeBench编程评测中均取得最优成绩

**论文**：Qwen3 Technical Report, arXiv:2505.09388


## 2025年下半年：Qwen3-Coder与专用模型扩展

**Qwen3-Coder（2025年7月）**：编程能力登顶全球开源模型阵营，代码能力与Agent调用能力取得重大突破。据OpenRouter统计，其单周调用量增长达1474%，跃居编程类模型第二

**Qwen3-2507**：社区反馈驱动的专项优化版，将Instruct-only和Thinking-only模型分开发布，在256K长上下文理解上显著增强，可扩展至1M

**Qwen3-Max-Thinking（2026年1月）**：总参数量超万亿（1T），预训练数据36T tokens，是阿里当时规模最大、能力最强的推理模型，采用Test-time Scaling的多轮推理策略


## 2026年：Qwen3.5与Qwen3.8——架构创新的深化

**Qwen3.5（2026年2月）**：
- 旗舰版**Qwen3.5-Plus**：397B总参数，17B激活参数，采用**Hybrid GatedDeltaNet架构**，原生多模态，支持201种语言，262K原生上下文可扩展至1M
- 性能媲美Gemini 3 Pro，登顶全球最强开源模型
- **Qwen3-Coder-Next**（2026年2月）：仅3B激活参数，在SWE-Bench上达到70.6%，匹配Claude Sonnet 4.0级别的编程能力，可在消费级硬件运行

**Qwen3.8-Flash-Next（2026年8月）**：这一版本展示了Qwen下一代架构的核心思路：
- **混合注意力**：Gated DeltaNet（高效“记住”）与Qwen Sparse Attention（QSA，精准“查找”）交替使用。QSA在微块级别操作，而非选择单个token，在1M上下文下Prefill和Decode阶段分别实现最高**7.6×和4.9×**的加速
- **Gated Residual**：将单一残差流扩展为4条并行分支，模型可根据内容动态决定从不同分支读取/写入信息，其中一条分支自然形成连接第一层到中后层的长距离通道
- **N-gram Embedding**：受DeepSeek Engram和Gemma 3n启发，引入**51B N-gram Embedding参数**，通过结合当前token与前几个token的局部上下文查表，在几乎不增加计算量的前提下扩展模型容量。这些参数可存放在Host Memory中异步Prefetch
- **Muon优化器**：与AdamW分工使用，对Attention、GDN、MoE Expert等二维线性映射权重使用Muon，Embedding和Router继续用AdamW

**参数规模**：Qwen3.8-Flash-Next为125B总参数，6B激活参数，外加51B N-gram Embedding和4B MTP

**解决的问题**：Qwen3.8-Flash-Next被定位为“Qwen4架构的实验性预览”，核心目标是在**不显著增加每token计算量**的前提下扩展模型容量，同时大幅降低长上下文下的延迟。在90% Prefix Cache命中率的线上场景中，1M上下文下的Prefill吞吐达到Qwen3.7-Plus的**8.6倍**


## 技术演进主线

**1. 架构效率的持续优化**：从Qwen2的GQA → Qwen2.5的MoE → Qwen3的混合推理 → Qwen3.8的Gated DeltaNet + QSA混合注意力。每一步都在解决“如何在更大参数、更长上下文下控制推理成本”这一核心矛盾。

**2. 开源生态的广度优先**：Qwen系列开源了300余个模型，覆盖0.5B到近4000B的全尺寸，以及LLM、编程、图像、语音、视频的全模态。衍生模型突破20万个，全球下载量突破10亿次，稳居开源大模型全球第一。

**3. 从“模型”到“智能体执行引擎”**：Qwen3开始强调原生Agent能力，Qwen3.8-Flash-Next的QSA设计明确针对“Agentic workloads increasingly dominate real-world usage”的趋势。
