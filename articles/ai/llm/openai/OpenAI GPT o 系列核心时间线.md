### 📅 OpenAI GPT/o 系列核心时间线

**2018-2020：奠基期**
* **GPT-1（2018）**：1.17亿参数，首次将 Transformer 用于预训练语言模型。
* **GPT-2（2019）**：15亿参数，展示了无监督多任务学习潜力。
* **GPT-3（2020）**：**1750亿参数**，首次提出“上下文学习”，奠定大模型范式。

**2023-2024：多模态与推理分叉**
* **GPT-4（2023.03）**：首次支持图文双模态输入。
* **GPT-4o（2024.05）**：**原生全模态**，文本/音频/图像端到端训练，语音响应延迟降至 232ms。
* **o1-preview（2024.09）**：**推理模型开端**，通过“先思考再回答”的 RL 训练，在 IMO 数学题上得分 83%（GPT-4o 仅 13%）。

**2025：效率与 Agent 化**
* **GPT-4.5（2025.02）**：定位“更大、更通用”，强调情感智能和创作，但计算昂贵。
* **GPT-4.1（2025.04）**：API 专用，指令遵循和编码精准度大幅提升，无关代码编辑从 9% 降至 2%。
* **GPT-5（2025.08）**：**内建思考**，不再需要手动切换模型，在编程和 Agent 任务上表现更强。

**2026：Agent 执行引擎**
* **GPT-5.5（2026.04）**：**专为 Agent 而生**。Terminal-Bench 2.0 达 **82.7%**，SWE-Bench Pro 达 **58.6%**，且完成同等任务 Token 消耗大幅降低，成本仅为前代 **1/35**。

### 💡 与开源路线的核心差异

* **能力验证方式**：闭源靠 **Benchmark 分数**（如 SWE-Bench 解决率）来证明能力；开源则直接公开架构和训练细节。
* **迭代节奏**：闭源是**发布即产品**，GPT-5.5 发布时已集成到 Codex 和 ChatGPT 中供付费用户使用；开源通常先发权重，后续依赖社区微调和部署。
