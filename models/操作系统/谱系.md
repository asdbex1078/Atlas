操作系统这张谱系图：一条产品线一个家族文件（Unix、BSD、Linux、Windows、macOS…）。
一个重要版本一条记录。发布、前代、基于、技术、亮点、突破、论文是公共字段，这里只声明操作系统特有的。

## 字段
- 内核:: 文字
- 运行在:: 指向 CPU
- 授权:: 文字

## 抽取说明
- **一个重要版本一条**（Unix V6、4.3BSD、Linux 0.11、Linux 2.6、Windows NT 3.1、Mac OS X 10.0…），名字用原文写法。
- **内核**写内核类型：`宏内核`、`微内核`、`混合内核`（原文明确说了才写）。
- **运行在**：这个版本首发 / 主要支持的 CPU，写 CPU 那张图里的型号名（下面列出了现有的），多个用「、」分开；CPU 图里没有的就不写这个字段，把原文写法放进 extra 的 `支持平台`。
- **基于**：派生自哪个系统（4BSD 基于 Unix V6、macOS 基于 NeXTSTEP），可以跨家族。
- 进程 / 内存管理的关键机制（分页、虚拟内存、抢占式多任务、对称多处理）放 **技术**，图里有的知识点写成 `[[知识点]]`。
