## Kimi k1.5
- 发布:: 2025-01
- 参数:: 未披露
- 技术:: 长上下文 RL、改进策略优化、不依赖 MCTS/价值函数/PRM
- 亮点:: 纯 RL 达到 o1 水平的推理能力。
- 突破:: 首次证明「简单 RL 框架」可训练出顶尖推理能力，开辟 context length scaling 新轴。
- 论文:: arXiv:2501.12599

## Kimi-VL
- 发布:: 2025-04
- 参数:: 16B
- 激活:: 3B
- 技术:: MoonViT 原生分辨率视觉编码器、NaViT 打包、MoE 语言解码器
- 亮点:: 小规模下在视觉感知和 OCR 任务上竞争力强。
- 突破:: 首个开源多模态模型。
- 论文:: arXiv:2504.07491
- 架构:: MoE

## Kimi K2
- 发布:: 2025-07
- 参数:: 1T
- 激活:: 32B
- 技术:: MuonClip 优化器、QK-Clip 权重裁剪、[[多头潜在注意力MLA]]、SwiGLU、多轮工具调用轨迹合成
- 亮点:: 全球首个万亿参数开源模型；Kimi 是第一个大规模使用 Muon 优化器的团队。
- 突破:: 用 QK-Clip 在权重更新后缩放 Query/Key 投影矩阵，把注意力 logits 控制在阈值内，解决超大规模 MoE 训练不稳定的问题。
- 论文:: arXiv:2507.20534
- 专家:: 384 专家激活 8 个
- Agentic 数据:: 从 GitHub 抓取 3000+ 真实 MCP 工具，分层领域演化合成 20000+ 合成工具，产生数万条 agentic 训练数据

## Kimi Linear
- 发布:: 2025-10
- 参数:: 48B
- 激活:: 3B
- 上下文:: 1M
- 技术:: KDA 混合线性注意力、channel-wise gating 遗忘门、3:1 KDA/全注意力交替
- 亮点:: 1M 上下文下 KV cache 减少 75%，解码吞吐提升 6 倍。
- 突破:: 给每个特征维度独立遗忘门，解决传统线性注意力在长序列上「遗忘」的问题，降低长序列推理的内存和计算开销。
- 论文:: arXiv:2510.26692
- 定位:: 轻量化部署
