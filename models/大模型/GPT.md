## GPT-1
- 发布:: 2018
- 参数:: 1.17亿
- 技术:: [[Transformer]]
- 亮点:: 1.17亿参数的预训练语言模型。
- 突破:: 首次把 Transformer 用在预训练语言模型上。

## GPT-2
- 发布:: 2019
- 参数:: 15亿
- 亮点:: 15亿参数，展示了无监督多任务学习的潜力。
- 突破:: 证明不做针对性监督训练，也能做多种任务。

## GPT-3
- 发布:: 2020
- 参数:: 1750亿
- 技术:: 上下文学习
- 亮点:: 1750亿参数，奠定了大模型范式。
- 突破:: 首次提出「上下文学习」：不改权重，靠提示里的示例完成新任务。

## GPT-4
- 发布:: 2023-03
- 技术:: 图文双模态输入
- 亮点:: 首次支持图文双模态输入。
- 突破:: GPT 系列第一次能同时接收图像和文本输入。

## GPT-4o
- 发布:: 2024-05
- 技术:: 原生全模态、文本/音频/图像端到端训练
- 亮点:: 原生全模态，语音响应延迟降到 232ms。
- 突破:: 文本、音频、图像放在一起端到端训练，不再靠多个模型拼接。

## GPT-4.5
- 发布:: 2025-02
- 亮点:: 定位「更大、更通用」，强调情感智能和创作，但计算成本高。
- 定位:: 更大、更通用

## GPT-4.1
- 发布:: 2025-04
- 亮点:: 指令遵循和编码精准度大幅提升，无关代码编辑从 9% 降到 2%。
- 定位:: API 专用

## GPT-5
- 发布:: 2025-08
- 技术:: 内建思考
- 亮点:: 编程和 Agent 任务上表现更强。
- 突破:: 思考能力内建，不用再手动切换模型。

## GPT-5.5
- 发布:: 2026-04
- 亮点:: 专为 Agent 设计：Terminal-Bench 2.0 达 82.7%，SWE-Bench Pro 达 58.6%，成本只有前代的 1/35。
- 突破:: 完成同样的任务，Token 消耗大幅降低。
- 定位:: Agent 执行引擎
- 发布形态:: 发布时已集成到 Codex 和 ChatGPT，供付费用户使用

## o1-preview
- 发布:: 2024-09
- 技术:: 先思考再回答的 RL 训练
- 亮点:: IMO 数学题得分 83%，GPT-4o 只有 13%。
- 突破:: 推理模型的开端：先思考再回答，从 GPT 主线分出推理这条路线。
