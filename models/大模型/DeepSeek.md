## DeepSeek-V3
- 发布:: 2024-12-26
- 参数:: 671B
- 激活:: 37B
- 前代:: DeepSeek-V2
- 技术:: [[多头潜在注意力MLA]]、细粒度专家分割、无辅助损失负载均衡、FP8 [[混合精度与量化]]训练、多Token预测（MTP）
- 亮点:: 训练成本只有约 557 万美元，每万亿 token 仅需 180K GPU 小时。
- 突破:: 第一个用 FP8 训成功的大规模 MoE 模型，证明了极致稀疏的 MoE 能用很低的训练成本做到顶尖性能。
- 论文:: arXiv:2412.19437
- KV缓存压缩:: 14倍
- 专家数:: 256个路由专家+共享专家
- 负载均衡方式:: 动态调整偏置项
- MTP推理:: 可结合投机采样加速

DeepSeek-V3 是 DeepSeek 2024 年 12 月发布的开源 MoE 大模型：总参数 671B、每个 token 激活 37B，上下文 128K。它的意义在于用很低的训练成本做到了和当时闭源一线模型接近的水平。

### 为什么需要它
稠密模型每个 token 都要过全部参数，参数量一上去训练和推理成本线性往上涨。V3 用 MoE 让每个 token 只走一小部分专家，再配一组省显存、省通信的工程设计，把成本压下来——技术报告给的训练开销约 278.8 万 H800 GPU 小时。

### 怎么运作
- **MLA**（Multi-head Latent Attention，V2 引入）：把 K/V 压成低维 latent 再缓存，KV Cache 大幅缩小
- **DeepSeekMoE**：细粒度专家 + 共享专家
- **无辅助损失的负载均衡**：靠给每个专家加可调 bias 平衡路由，不再往 loss 里加惩罚项
- **MTP**（Multi-Token Prediction）：训练时多预测后面几个 token，增加训练信号
- **FP8 混合精度训练**，预训练约 14.8T token

### 容易搞混的
- **V3 里没有 Engram。** Engram 是 DeepSeek 2026 年 1 月论文里提出的另一个模块（哈希 n-gram 查表记忆），和 V3 是两回事。
- 和 DeepSeek-R1：R1（2025-01）是在 V3 基座上用强化学习训出来的推理模型。

## DeepSeek-R1-Zero
- 参数:: 671B
- 基于:: DeepSeek-V3
- 技术:: 纯强化学习训练推理能力、规则奖励机制

## DeepSeek-R1
- 发布:: 2025-01-20
- 参数:: 671B
- 基于:: DeepSeek-V3、DeepSeek-R1-Zero
- 技术:: 纯强化学习训练推理能力、多阶段训练+冷启动数据、规则奖励机制
- 亮点:: 数学基准测试 79.8%。
- 突破:: 首次证明大语言模型的推理能力可以通过纯强化学习提升，大幅减少对人类标注数据的依赖。
- 论文:: arXiv:2501.12948
- 期刊:: Nature 645, 633–638 (2025)
- 奖励:: 准确性奖励+格式奖励，不用神经奖励模型，避免奖励劫持
- 冷启动数据作用:: 解决可读性和语言混用问题
- 工具调用:: 不支持原生工具调用

## DeepSeek-V4-Pro
- 发布:: 2026-04-24
- 参数:: 1.6万亿
- 激活:: 49B
- 上下文:: 100万 tokens
- 前代:: DeepSeek-V3.2
- 技术:: CSA + HCA 混合注意力架构、mHC（流形约束超连接）、Muon优化器
- 亮点:: 百万 token 下 KV 缓存只有 V3.2 的 10%，计算量只有 27%。
- 突破:: 性能不降的前提下把上下文扩到百万 token，把长文本推理成本降到能工程化落地的水平，解决了传统注意力在长上下文下计算量平方级增长的瓶颈。
- CSA:: 压缩稀疏注意力，每4个token合并为1个压缩条目+闪电索引器筛选top-k
- HCA:: 重度压缩注意力，128倍压缩率
- mHC:: 残差映射矩阵约束在双随机矩阵流形上，解决深层堆叠数值不稳定
- 优化器:: Muon 替代 AdamW，对梯度矩阵做近似正交化
- 技术报告:: 58页，未提供链接
