# CPU实模式与平坦模式

图中占位节点，未展开。与内存寻址模式（实模式 / 保护模式 / 平坦内存模型）相关，待学习补充。

> 补充自《articles/硬件/CPU》（2026-10-12）：原文讲清了实模式的寻址方式和 386 的平坦寻址

## 实模式

8086（1978）确立了 x86 的基本寻址模型：**段寄存器左移 4 位加偏移，寻址 1MB 空间**。这是**实模式（Real Mode）**的本质——没有内存保护，所有程序运行在「上帝权限」下。CMU 的教材将其描述为 "Basis for IBM PC & DOS, 1MB address space"。

- （补充）物理地址 = 段 × 16 + 偏移，例如 `1234:0010` → `0x12340 + 0x10 = 0x12350`。同一个物理地址可以有很多种「段:偏移」写法。
- （补充）今天的 x86 CPU 上电时仍然处在实模式，BIOS / 引导程序要自己切到 [[保护模式]]（再切到 64 位长模式）——四十多年的向后兼容就体现在这里。

## 平坦模式

80386 首次支持 32 位线性地址，并引入**平坦寻址（flat addressing）**，使 x86 能够运行 Unix：把所有段的基址设为 0、段长设为 4GB，程序眼里只有一个连续的 32 位地址空间，段机制形同虚设，内存隔离交给 [[分页]]。64 位模式下段机制几乎被完全架空，默认就是平坦地址空间（见 [[x86-64]]）。

- （补充）DOS 程序直接往 `B800:0000` 写字节就能在屏幕上显示字符——实模式下没有任何东西拦着它写显存，也没有东西拦着它改别人的内存。
