# 现代Intel微架构

现代 Intel：
- 前端：CISC 指令集
- 后端：将复杂指令拆成类似 RISC 的 μops（微操作）

> **年份锚点：1995。** Pentium Pro（P6）第一次把 x86 的 CISC 指令在前端译码成类 RISC 的 μops

## P6：「CISC 外壳 + RISC 内核」是怎么来的

Pentium Pro（1995）的 P6 微架构被广泛认为是现代 x86 高性能 CPU 的**范式起点**：将复杂的 x86 指令**动态翻译为 RISC 风格的微操作（micro-operations）**，然后在硬件层面分析、重排序和重命名，以发现可并行执行的操作。它的流水线包含额外的译码阶段，专门把 IA-32 指令翻译为缓冲的微操作序列。

P6 引入的关键技术（至今仍是主流 CPU 的基础）：[[乱序执行]]、[[寄存器重命名]]、[[推测执行]]、超流水线（5 级 → 14 级，见 [[指令流水线]]）、3 路 [[超标量]]、分离的 L1 缓存（8KB 指令缓存，每周期取 16 字节送入译码器）。

## 例子

- （补充）`add [mem], eax` 这样一条「读内存-加-写回内存」的 x86 指令，在 P6 之后的核心里会被拆成 load、add、store 三个 μop，各自进乱序窗口调度——外面看是一条 CISC 指令，里面跑的是三条 RISC 式操作。
