# 超标量

## 描述

[[指令流水线]] 让多条指令「错开」重叠执行，超标量则让多条指令「并排」同时执行：CPU 里有好几套执行单元，每个周期可以译码、发射不止一条指令。

## 核心内容

- **Pentium（1993）**：超标量（双流水线），x86 第一次一个周期能执行两条指令。
- **P6（1995）**：**3 路超标量**设计，每周期可译码 / 执行多条指令；Papworth 把「宽超标量」列为 P6 数据流处理的四大特性之一。
- （补充）**按序超标量的天花板**：Pentium 的两条流水线（U / V 管）只能同时发两条**互不相关**的指令，一旦相邻两条有依赖，另一条管子就空转。要把宽度真正用满，就得允许不按程序顺序发射——这正是 [[乱序执行]] 要解决的问题。所以超标量和乱序执行是一对：前者提供并行的执行单元，后者负责找到能并行的指令。
- （补充）今天的高性能核心是 6～10 路宽（Apple M 系列的大核前端每周期能译码 8 条以上）。

## 例子

- （补充）`a = x + y; b = z * w;` 两条之间没有依赖，超标量 CPU 可以在同一个周期把加法送进整数 ALU、把乘法送进乘法器；而 `a = x + y; b = a * w;` 的第二条必须等第一条，按序超标量这时只能空一个发射槽。

## 关系
- 依赖:: [[指令流水线]] — 多条流水线并排
- 演化为:: [[乱序执行]] (1995) — 按序超标量用不满宽度，催生乱序发射
